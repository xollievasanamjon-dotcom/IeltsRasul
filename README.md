# IELTS.RASUL — Mobile PWA (React + Vite + Live Gemini Examiner)

Полноценное мобильное веб-приложение (PWA) для подготовки к IELTS Academic 7.0–8.0 в режиме Beast Mode (28 дней).

## Что внутри
- **28-дневный трекер Beast Mode** с точным расписанием на каждый день (4 часа/день) и графиком прогресса по мокам.
- **Error Wall** — лог твоих реальных точек слива баллов (T/F/NG, Matching Headings, Listening Part 3 MCQ, Task 1 Overview и др.).
- **Интерактивный Writing Lab** — пошаговые схемы всех 5 типов Task 2 (S1–S12) и всех 6 типов Task 1, живой детектор клише (подсвечивает `nowadays`, `firstly`, `very bad` в реальном времени), быстрая вставка рамок Band 8 (Noun Clauses, Inversion, Concession) и **реальная проверка эссе через Gemini 2.5 Flash API** (по всем 4 официальным критериям IELTS).
- **Экзаменационные таймеры со звуковым сигналом:** Reading Split Timer (15 / 20 / 25 мин), Writing Timer (20 / 40 мин), Speaking Cue Card Timer (1 мин подготовка → 2 мин ответ).
- **Медиатека (40+ источников):** Netflix, HBO, Apple TV+, аниме, фильмы, спорт, игры/Tech, книги, эссе, YouTube и подкасты с поиском и фильтрами.

## Как залить на телефон за 2 минуты (бесплатно)
1. Распакуй ZIP и загрузи папку в бесплатный репозиторий на **GitHub** (или перетащи папку прямо в **Netlify Drop** после `npm install && npm run build`).
2. Самый быстрый путь через **Vercel**:
   - Зайди на `vercel.com` → **Add New Project** → подключи репозиторий с этой папкой → нажми **Deploy**.
   - Через 40 секунд получишь свою постоянную HTTPS-ссылку `https://ielts-rasul.vercel.app`.
3. Открой эту ссылку в **Chrome на Android** (или Safari на iPhone) → меню «Добавить на главный экран» (**Install App**). Приложение установится с собственной иконкой `IR` и будет открываться на весь экран без адресной строки.

## Как включить живого ИИ-экзаменатора (бесплатно)
1. Зайди на `aistudio.google.com/apikey` и создай бесплатный ключ **Gemini API**.
2. В приложении нажми на иконку шестерёнки (Настройки) в правом верхнем углу и вставь ключ — он сохранится только локально в памяти твоего телефона (`localStorage`).
3. Пиши эссе во вкладке **Writing** или ответ во вкладке **Таймеры → Speaking** и нажимай **«Проверить через Gemini Examiner»**.
